# The bench

Twelve advisors, chosen so their lenses collide. `SKILL.md` loads only the
seated advisors' files. Each dossier follows the same headings so a take can
be built the same way every time: Lens, Core frameworks (with work and year),
Documented positions (each with a source), Signature questions (paraphrases,
never quotes), Best for / blind spots (with the critic named), Voice notes,
Key works, Status.

Dossiers are written in our own words from the advisors' published work. The
bench and the dossier idea come from Corey Haines's
[marketingskills](https://github.com/coreyhaines31/marketingskills) (MIT).

dossiers say so, and the skill prefers a research pass for anything
time-sensitive about them.
