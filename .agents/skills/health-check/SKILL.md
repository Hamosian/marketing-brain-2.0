# Health Check

1. Run the shared preflight and report real failures.
2. Validate the blank template or the local company profile, depending on setup state.
3. Check source ownership and verification dates for configured company knowledge.
4. Flag missing evidence, stale definitions, conflicting claims, and unverified account identity.
5. Check skill references, metadata, registry, and generated mirror consistency.
6. Treat blank templates as intentionally unconfigured, not missing employee data.
7. Recommend specific changes without filling gaps from an old company or model memory.

Return failures first, then readiness gaps and recommended maintenance.
The privacy scanner covers known patterns, not all possible private information.
