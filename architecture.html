The Flywheel · why the docs don't go stale
01 · NEW
A task Claude hasn't seen before
Something off the beaten path - a new platform, a one-off workflow, a tribal-knowledge moment.
02 · TEACH
You guide Claude through it
Correct mistakes, point at the right dashboard, explain why we do it that way.
03 · CAPTURE
/retro commits the learning
Claude updates the relevant system doc or skill and opens a PR. Memory becomes shared, not personal.
04 · COMPOUND
Next time it takes seconds
The whole department benefits. Effort drops, capability compounds. Doing real work IS the maintenance.
