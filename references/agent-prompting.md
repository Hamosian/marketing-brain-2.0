# Agent Prompting

## Block 1: Scope
Define one user outcome, trigger, exclusions, and completion criteria.

## Block 2: Context
Load only relevant verified company sources. Missing facts remain unknown.

## Block 3: Evidence
State source, date, metric definition, uncertainty, and assumptions.

## Block 4: Workflow
Separate diagnosis, drafting, validation, and authorized external actions.
Handle missing inputs and failures explicitly.

## Block 5: Output
Give the user a useful result with sources, next actions, and limitations.

## Block 6: Review
Keep independent critique separate from drafting. Use synthetic cases to test
failure modes, scope boundaries, and unsupported claims.
