# Messaging and brand story

Distilled versions of the messaging and positioning source documents owned by the Product Marketing team (part of Sivan Mazuz's Marketing org), shared in July 2026. Load the relevant file whenever a task involves writing copy, positioning, campaign briefs, landing pages, ads, social posts, or any external-facing content.

The Google docs remain the source of truth for the full detail. These files are working distillations: if a source doc changes materially, update the matching file here.

## Usage rules

- **Externally usable as-is:** the "Riverside in a nutshell" blurbs and the partner-facing brand guideline section in `messaging-framework.md`.
- **Internal resource only:** the detailed per-ICP frameworks. They guide the creation of external materials but must not be published verbatim.
- **Research inputs, not copy:** `community-voice.md` and `power-user-interviews.md` are voice-of-customer evidence. Quote users only with permission handling per the LinkedIn and privacy rules.
- **Customer side lives elsewhere:** the per-ICP frameworks describe what Riverside offers (a Value Map). To build the matching Customer Profile (ranked jobs, pains, gains with evidence tags) from these VoC files plus `.claude/skills/inbound-demo-reply/pain-map.md`, and to check fit between the two, use `/value-proposition-canvas`.
- For visual identity (colors, typography, components), use `references/design-system/` and the `/riverside-brand-guidelines` skill. This directory covers verbal identity and story.
