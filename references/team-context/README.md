# Team context

Point-in-time context digests for Nir Taranto's Growth Marketing functions,
drawn from each team's own weekly and monthly reports. One file per team:
**performance, insights, blockers, and big bets** synthesized across the period,
with links back to every source report.

These are **snapshots, not live data.** They capture what a team's reports said
at a moment in time so the Marketing OS (and `/chief-of-staff`) has standing
background on each function's trajectory. For current numbers, route to
`/rivermind:ask`. For the underlying reports, follow the per-month source links.
Refresh a file by re-reading the newer reports and updating it.
