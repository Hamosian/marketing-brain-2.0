# Riverside product knowledge

Distilled reference of Riverside's Help Center (support.riverside.com) - every top-level category, section, and article summarized, plus a consolidated glossary and plan-tier breakdown. This is Marketing's copy of *product* knowledge (what the product does, how it's organized, what's gated by plan), as opposed to `references/messaging/` (how we talk about it externally) or `references/design-system/` (how it looks).

Load `help-center-reference.md` whenever a task needs to know how a Riverside feature works, what a plan includes, or how the product is organized - feature pages, comparison pages, sales/CS enablement, support-adjacent copy, or answering "does Riverside do X" questions. The `/riverside-product-knowledge` skill wraps this file for direct product Q&A; other skills (content, website, SEO, paid) can load it directly for accuracy on product claims.

## Usage rules

- **Pricing and plan names are directional, not authoritative.** Riverside's own "Subscription plans: Overview" article intentionally defers to the live pricing page rather than listing tiers, and third-party sources disagree on names and prices. Always verify current tier names/prices/inclusions at riverside.fm/pricing before publishing anything with a number in it.
- **Beta features move fast.** AI credits, AI B-roll, and VideoDub are explicitly in beta as of this snapshot - check current availability before promising a feature to a specific plan or region.
- **Re-verify quarterly.** This is a point-in-time snapshot (July 2026), not live data. If you learn something that contradicts this file, update it and open a PR - don't just note it in chat.
- For visual identity, use `references/design-system/` and `/riverside-brand-guidelines`. For verbal identity, positioning, and voice-of-customer, use `references/messaging/`. This directory is the product's factual/functional layer underneath both.
