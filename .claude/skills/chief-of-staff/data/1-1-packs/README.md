# 1-1 pack drafts

The scheduled 9:00 run writes one file per 1-1 today here, named
`YYYY-MM-DD-<lead-slug>.md` (`erika`, `raz-navon`, `savion`, `hanan`, `abel`).
Each file is the exact message text the pack would send, followed by a `## Sources`
list of the ledger rows and permalinks it drew on. Nothing here has been sent.

In chat, `/chief-of-staff packs` loads today's drafts, rebuilds any that are stale
(older than three hours, or whose sources changed), shows them for approval and
sends on Nir's word. Drafts older than seven days are deleted on the Sunday run.

Spec: `../../knowledge/1-1-pack.md`.
