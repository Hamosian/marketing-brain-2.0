# Marketing Brain

## Context and Boundaries

Read `CLAUDE.md` and the configured local company profile. Missing company facts
remain unknown. Use only verified sources and authorized integrations for this company.
Keep private records and reports in ignored `local/` or approved company systems.
Drafting does not authorize sending, publishing, spending, or changing live records.

## Workflow

1. Classify the request as brief, investigate, plan, execute, measure, or learn.
2. Establish the desired result, company, audience, time range, constraints, and evidence.
3. Consult the routing table in `CLAUDE.md`. Use the narrowest matching workflow.
4. For cross-domain work, separate questions by domain and reconcile conflicting evidence.
   Delegate only when the runtime permits it; provide scope, evidence, and output requirements.
5. Keep live work state in the configured task system; keep reusable methods in this repository.
6. Return the decision, supporting evidence, owner if known, next action, and uncertainty.
7. Offer a generic learning for `retro` only when it improves future work.

A missing connection is not zero activity. Continue with supplied material and label limitations.
