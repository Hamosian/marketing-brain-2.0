What to remember

One rule, three habits

If a skill exists for the task, use it. It carries the whole workflow with it.

    Not sure where to start

  2. 2

    A number or a metric definition

  3. 3

    Learned something the hard way

    /retro writes it back to the repo, so everyone gets it
